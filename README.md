# Calculadora Científica - Práctica 2

## 🚀 Descripción del proyecto
Programa desarrollado en Python que amplía las funcionalidades de una calculadora modular. Permite realizar operaciones matemáticas avanzadas, controlando errores de entrada y evitando fallas por divisiones entre cero o valores no válidos. El proyecto está estructurado de manera modular separando la lógica matemática de la interfaz de usuario.

## 📋 Tabla de operaciones y estados

| N.° | Funcionalidad | Descripción / Condição | Estado |
|:---:|---|---|:---:|
| 1 | Potencia | Calcular una base elevada a un exponente. | Completado |
| 2 | Módulo | Obtener el residuo de una división. | Completado |
| 3 | Raíz cuadrada | Calcular la raíz cuadrada de un número (controla negativos). | Completado |
| 4 | Porcentaje | Calcular un porcentaje de una cantidad. | Completado |
| 5 | Valor absoluto | Obtener el valor absoluto de un número. | Completado |
| 6 | Factorial | Calcular el factorial de un entero no negativo. | Completado |
| 7 | Promedio | Calcular el promedio de varios números. | Completado |
| 8 | Redondeo | Redondear un resultado a los decimales indicados. | Completado |
| 9 | Validación de entradas | Controlar entradas no numéricas para evitar fallas. | Completado |
| 10 | División por cero | Evitar divisiones entre cero y módulo con divisor cero. | Completado |
| 11 | Mejorar el menú | Organizar las operaciones en un menú claro. | Completado |
| 12 | Repetir operaciones | Permitir realizar varias operaciones consecutivas. | Completado |
